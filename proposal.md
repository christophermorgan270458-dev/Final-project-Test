\# Title

Personal Gaming History Tracker



\## Repository

https://github.com/christophermorgan270458-dev/Final-project-Test



\## Description

This would be an application that lets users input their personal game history. After input all information will be stored on csv files and would allow the history to be edited and organized.



\## Features

\- Game Library Management

&#x09;- Allows users to add, view, edit and delete games from their history

\- Game Information Tracking

&#x09;- Store game title, platform, genre, hours played, personal rating and completion status.

\- Search and Filtering

&#x09;- Allow users to search their game library and filter games by title, genre, platform, or completion status.

\- Gaming Statistics

&#x09;- Calculate statistics such as total games played, total hours, average ratings, and most-played genres.

\- CSV Storage

&#x09;- Simply use csv files to store all information.

\- User Interface

&#x09;- If I am able to after I complete all the previous features, I would make a interface with buttons, menus, and a dashboard.





\## Challenges

\- Learning how to make statistics and maybe graphs using the stored data.

\- Learning how to make menus and on my own handle user input in terminal.

\- Figuring how to make a graphical interface using Pygame or other libraries like Tkinter or CustomTkinter



\## Outcomes

Ideal Outcome:

\- Create a fully working game history tracker that allows the user to manage their history, track statistics, and store the history using csv files. Ideally the interface is fully working with ways to view and manage all of the features.



Minimal Viable Outcome:

\- Create a working terminal-based application that allows users to add, view, edit, delete, and search for games while saving all information to CSV files. The application will also include basic gaming statistics.
